# 视频爆款分析

这个 skill 用于把一条短视频拆成可复盘、可改稿、可复刻的结论。

## 输入优先级

优先收集这些信息；没有就基于已有材料分析，不要卡住：

1. 视频文件、公开视频 URL、关键帧、转录文本或上游 `video-analysis` 输出
2. 标题、封面、发布时间、平台、账号类型、目标人群
3. 播放、点赞、评论、收藏、分享、完播率、5 秒留存、平均观看时长、涨粉等数据

如果输入来自 `douyin-video-fetch`，同时使用：

- `desc`
- `author`
- `duration_ms`
- `width` / `height`
- `statistics.view_count`
- `statistics.comment_count`
- `statistics.digg_count`
- `statistics.collect_count`
- `statistics.share_count`
- `statistics.recommend_count`

抖音播放量优先使用 `statistics.view_count`，它来自 `aweme_detail.hot_list.view_count`。不要用原始 `statistics.play_count` 替代播放量。

## 分析模式

### 有数据模式

当有播放和互动数据时，必须先做数据归因：

- 播放量：判断流量层级
- 点赞率：`digg_count / view_count`
- 评论率：`comment_count / view_count`
- 收藏率：`collect_count / view_count`
- 分享率：`share_count / view_count`
- 互动结构：评论、收藏、分享谁更突出

如果缺某个指标，只计算已有指标，并明确缺失项。

### 无数据模式

当没有播放和互动数据时，不要假装有数据。改做预测分析：

- 判断第一帧、前 3 秒、标题承诺、选题人群、情绪密度、信息密度
- 标出最可能影响播放、完播、互动、转发的因素
- 给出“如果数据不好，最可能坏在哪”的假设

## 必看维度

- 选题：人群、需求强度、稀缺角度、平台适配
- 标题/封面/首帧：点击理由、悬念、视觉奇观、标题兑现时间
- 开头钩子：前 1-3 秒是否直接进入冲突、利益、反常识或强画面
- 结构节奏：每 3-5 秒是否有新信息、新情绪或新画面
- 内容价值：爽感、笑点、萌点、情绪、知识、审美、故事反转
- 人设关系：角色是否容易记住，关系是否 3 秒内看懂
- 视听表现：构图、字幕、配色、声音、剪辑、动效、AI痕迹
- 互动触发：评论争议、共鸣、提问、收藏理由、转发理由
- 平台机制：时长、画幅、标签、发布时间、账号垂类匹配
- 可复刻性：能否抽成脚本模板、系列模板、标题模板、封面模板

## 判断口径

- 高播放低互动：可能是点击/推荐强，但情绪、收藏、评论触发弱
- 高点赞低评论：内容好懂、情绪顺，但讨论点弱
- 高收藏：方法、资料、审美参考、教程价值强
- 高分享：强共鸣、强新奇、强社交货币
- 高评论：争议、提问、代入、槽点、角色关系强
- 高分享率优先级很高，通常说明内容具备破圈传播点

## 注意事项

- 不要只夸内容，要给出可执行改法。
- 不要把单条视频结论泛化成绝对规律。
- 不同平台的数据阈值不同，除非用户提供账号基准，否则只做相对判断。
- 如果视频无法读取，但有标题、封面、关键帧或数据，也要基于可用信息分析，并说明限制。
