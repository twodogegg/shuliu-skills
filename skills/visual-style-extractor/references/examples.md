# 输出示例

## 人物海报风格提取

用户提供一张冷灰紫人物海报并要求提取可复用风格。

```text
【主体提取】
主体：冷灰紫幻想人物海报中的女性角色
主体特征：半身肖像，人物偏右站位，神情清冷，银色轻未来配饰，服装带透明材质细节
可替换为：其他人物、虚拟角色、香水或珠宝产品

【风格提示词】
主体替换为【xxx】，生成一张冷灰紫幻想海报风格的竖版画面。主体偏右构图，左侧保留大量留白，整体采用低饱和银灰、淡薰衣草紫和冰蓝色调。使用柔光棚拍质感、浅阴影、低对比和轻微雾面柔焦，加入透明材质与银色金属点缀。背景极简干净，可加入极细、低透明度的竖排英文和小字号档案式排版，但不要抢主体。

【可替换部分】
主体：替换为人物、角色或产品。
场景：保持极简冷灰背景，或替换为同色系抽象影棚。
文字：保留细字版式但替换文案，也可以完全不要文字。
```

## 精确改图

用户要求：“把草地改成世界杯足球场的天然草地，其他不变。”

```text
修改图片中的草地为世界杯足球场质感的天然草地，草叶细腻、真实、有自然深浅变化，不要尼龙塑料感。
其他的构图、镜头视角、主体位置、光影、色调、背景、材质、画面比例和整体风格保持不变。
```

## 使用第二张参考图

用户要求保留图 1 构图，只借用图 2 的金属质感。

```text
修改图 1 中主体表面的材质，参考图 2 的拉丝银色金属质感，只参考金属纹理、反光强度和冷灰色调，不要复制图 2 的形状或构图。
图 1 其他的构图、镜头视角、主体位置、光影、背景、画面比例和整体风格保持不变。
```
