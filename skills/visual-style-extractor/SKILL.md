# 视觉风格提取器

## 核心任务

从参考图片中提取可复用的视觉规则，并生成可直接用于生图或改图的提示词。默认只输出提示词，不写长篇审美分析；用户明确要求分析时再解释判断依据。

用户明确要求直接生成或编辑图片时，先整理最终提示词，再交给可用的图像工具执行。

## 输入优先级

接受以下输入：

- 单张参考图片
- 多张参考图片
- 图片加文字要求
- 沿用参考风格生成新内容
- 只修改现有图片中的局部

将图片视为风格证据，将用户的文字要求视为最高优先级。用户的新要求与参考图冲突时，以文字要求为准，并保留不冲突的风格特征。

## 区分内容与风格

不要照搬参考图中的全部对象。先区分：

- **内容**：具体人物、产品、Logo、文字、姿势、道具、品牌、背景物件等一次性元素。
- **风格**：构图、镜头、配色、光线、材质、氛围、版式密度、字体气质、渲染媒介和整体情绪。

仅在用户明确要求保留，或目标结果确实依赖时保留内容元素。不要主动复制水印、账号 ID、随机 Logo 或无关文字。

## 提取维度

按需要识别以下维度，不要为了凑齐字段而虚构：

1. 图片类型：产品照、人物海报、美食摄影、包装渲染、信息图、电影剧照、编辑版式等。
2. 构图：画幅、主体位置、留白、裁切、前后景、景深。
3. 镜头：正面、俯拍、三分之四视角、近景、长焦压缩、微距、平铺等。
4. 配色：主色、点缀色、饱和度、对比度、冷暖和明度范围。
5. 光线：软硬、自然光或棚拍、方向、阴影、反光、雾气和辉光。
6. 主体处理：姿态、表情、造型、排列、轮廓、比例和动作。
7. 材质纹理：玻璃、金属、织物、液体、皮肤、纸张、烟雾、石材等。
8. 背景环境：极简、真实场景、抽象布景、商业影棚、干净桌面等。
9. 字体版式：只提取排版行为与字体气质，不复制原文，除非用户明确要求。
10. 整体情绪：高级、干净、梦幻、运动、复古、未来、自然、手作等。

## 工作流程

1. 识别参考图的主体及必须保持的内容。
2. 提取最显著、可迁移的风格锚点。
3. 合并用户新增或修改要求。
4. 根据任务选择通用风格、新图生成或精确改图格式。
5. 删除与目标无关的原图内容、文字、水印和品牌信息。
6. 检查提示词是否可直接复制使用。

需要参考完整示例时，读取 [examples.md](references/examples.md)。

## 输出格式

### 通用风格提取

始终把参考图主体单独列出，方便替换：

```text
【主体提取】
主体：[参考图中的主要主体]
主体特征：[外形、姿势、服装、材质、表情或产品细节]
可替换为：[适合套用同一风格的其他主体]

【风格提示词】
[一段可直接复制的中文提示词；需要替换主体时使用“主体替换为【xxx】”]

【可替换部分】
主体：[可替换内容]
场景：[可替换内容]
文字：[保留排版、替换文字或不使用文字]
```

### 沿用风格生成新图

只输出：

```text
生成一张[目标主体或图片类型]。
参考图的风格规则为：[构图、配色、光线、材质、氛围和版式]。
[合并用户的新要求]。
保持[关键风格锚点]，不要复制参考图中的[无关内容、Logo、水印或文字]。
```

### 精确修改现有图片

只描述需要修改的区域，然后锁定其余内容：

```text
修改图片中的[对象或区域]为[目标变化]。
其他的构图、镜头视角、主体位置、光影、色调、背景、材质、画面比例和整体风格保持不变。
```

存在第二张参考图时：

```text
修改图片中的[对象或区域]，参考图 2 的[具体特征]，只参考[所需特征]，不要改变其他内容。
其他的构图、镜头视角、主体位置、光影、色调、背景、材质、画面比例和整体风格保持不变。
```

## 写作规则

- 默认使用中文。
- 提示词具体但不堆砌。
- 不单独输出负面提示词；必要的规避要求直接融入正常描述。
- 用户说“只改一点”时，缩短提示词并强化“保持不变”。
- 参考图含文字时，只在文字属于目标版式时保留字体和排版特征。
- 多张参考图必须说明每张图分别贡献哪些特征，避免混合冲突。
- 风格有歧义时，优先提取最明显的锚点，不因次要信息追问用户。

## 输出前检查

确认结果：

- 提取的是可复用风格，而不是简单罗列物体。
- 已合并用户的新增要求。
- 未复制无关水印、账号 ID、Logo 或文字。
- 精确改图只描述必要变化并锁定其余内容。
- 通用风格输出包含独立的“主体提取”部分。
- 提示词无需二次整理即可使用。
