# 参数约束覆盖

生成 OpenAPI 前，为每个参数和 Schema 字段建立来源约束清单。每条来源限制都必须有明确去向，不能因为字段和类型已经存在就视为完成。

## 清单字段

逐项记录：

- 字段路径和类型
- 必填、条件必填和非空要求
- 枚举、默认值和示例
- 字符长度、数值范围和数组数量
- 文件格式、文件大小、媒体尺寸、比例、时长和帧率
- 字段依赖、跨元素组合、互斥关系和状态相关规则
- 来源位置
- OpenAPI 落点：Schema 关键字、字段说明或未决冲突

## 映射原则

1. 能由 JSON Schema 表达的限制必须机器化，不得只写自然语言。
2. 无法由 Schema 验证的媒体内容限制必须完整写入最接近的字段说明。
3. 条件和组合规则既要尽可能机器化，也要保留用户可读说明。
4. 来源存在矛盾时保留两处原始事实并报告冲突，不擅自选择。
5. 导入后回读请求模型，逐项抽查 required、enum、范围、数组限制和完整说明；不能只回读接口 path。

## 完成条件

约束清单中的每一项必须标记为“已机器化”“已写入说明”或“已报告冲突”。任何未落点约束都阻止最终导入或完成声明。
