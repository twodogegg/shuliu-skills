# Consistency Playbook

## 1. Multi-screen product or UI project
Use when the source material is a PRD, app flow, dashboard plan, or feature specification.

### What to preserve
- product name
- brand tone
- sidebar / topbar shell or equivalent frame
- typography feel
- palette
- spacing density
- recurring component patterns
- realistic UI content style

### What can change
- the active page
- core page modules
- charts, tables, forms, and page-specific actions

## 2. Comic / manga / manhua / webtoon
Use when the source material is a chapter outline, script, dialogue sheet, or panel plan.

### What to preserve
- character appearance
- costume and accessories
- world and location cues
- line art quality or rendering style
- recurring props
- emotional continuity

### What can change
- camera angle
- pose
- panel beat
- scene action
- dialogue moment

### Prompt reminders
Include:
- shot size
- camera angle
- action beat
- emotional beat
- notable props
- background specificity

## 3. Storyboard / cinematic frame sequence
Use when the source material is shot-based or scene-based.

### What to preserve
- cast identity
- location layout
- time of day
- blocking
- mood and lighting

### What can change
- lens distance
- composition
- action beat
- cut progression

## 4. Poster or campaign series
Use when the project is a family of visuals for a launch, campaign, or event.

### What to preserve
- visual motif
- campaign palette
- typography treatment
- logo placement
- mood

### What can change
- message focus
- featured subject
- key iconography
- local composition

## 5. Character / environment pack
Use when the project is a design pack.

### What to preserve
- face shape and landmarks
- hair shape and color
- body proportions
- signature clothing and props
- style and palette

### What can change
- pose
- expression
- outfit variant if requested
- turnaround angle
- sheet purpose

## Universal fallback
When unsure, preserve these first:
1. main subject identity
2. style and palette
3. environment / world cues
4. continuity objects
5. aspect ratio and framing rule
