# Asset Notes

## Character References

Put fixed creator or persona images in `assets/character/`.
Use these images to keep the same person, face, hairstyle, outfit direction, and creator identity when generating cover prompts.

## Visual References

Put cover examples, icon references, UI screenshots, Notion screenshots, app screenshots, color references, and layout references in `assets/reference-images/`.
Use these images as style and composition direction, not as exact copies.

## Default Rules

- Keep the character consistent unless the user asks to change it.
- Use the newest or most relevant reference image when references conflict.
- Prefer a clear thumbnail hierarchy: character, main title, and one strong visual focus.
- Avoid too many small words or too many icons.
